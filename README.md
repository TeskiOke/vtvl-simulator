## 📌 1. Концепция миссии и стратегическое назначение

Проект представляет собой программный комплекс численного математического моделирования, наведения, стабилизации и 3D-визуализации многоразовой ракетно-космической системы орбитального класса (аналог SpaceX Starship и перспективных отечественных МТКС).

Система моделирует полный замкнутый цикл глобального космического полёта:
1. **Активный участок выведения:** Вертикальный старт со стола, гравитационный разворот (Gravity Turn) и набор первой космической скорости ($V_I = 7\,788$ м/с) на круговой опорной орбите высотой $H = 200\dots 250$ км;
2. **Орбитальный полёт ($\ge 2$ витков):** Автономное кеплеровское движение вокруг планеты Земля ($\sim 80\,000$ км пути, $\sim 3$ часа) с учётом суточного вращения Земли и вековой прецессии узлов под действием зональной гармоники геоида $J_2$;
3. **Тормозной импульс схода с орбиты (Deorbit Burn):** Выдача ретроградного импульса маршевых двигателей ($\Delta V \approx 140\dots 200$ м/с) для снижения перигея в плотные слои атмосферы ($h_p \approx 30\dots 40$ км);
4. **Гиперзвуковое атмосферное торможение (Belly-Flop):** Спуск плашмя при угле атаки $\alpha \approx 60^\circ$ с рассеиванием кинетической энергии об атмосферу и торможением от $7.8$ км/с до дозвуковой скорости $250$ м/с за счёт лобового сопротивления и плиточной теплозащиты (TPS);
5. **Аэродинамический боковой манёвр (Cross-Range):** Смещение трассы планирования до $\pm 1\,500$ км за счёт крена корпуса для наведения на произвольно выбранную географическую точку планеты;
6. **Терминальный манёвр и посадка VTVL:** Динамический переворот в вертикаль (Flip Maneuver) на высоте $800$ м и режим Hoverslam / Suicide Burn с мягким вертикальным касанием посадочных опор ($|V_y| \le 2.5$ м/с).

* **Вертикальная скорость касания:** $|V_y| \le 2.5$ м/с;
* **Горизонтальная скорость:** $|V_x| \le 1.0$ м/с;
* **Угол отклонения от вертикали:** $\theta \le 3.0^\circ$;
* **Максимальная перегрузка входа:** $n_{max} \le 4.5\,g$;
* **Пиковая температура обшивки:** $T_{skin} \le 1\,600^\circ\text{C}$.

## 🔬 4. Математический аппарат физического ядра

Физическое ядро разработано на чистом C# и **полностью изолировано от движка Unity**:
* **Не используется Unity PhysX / Rigidbody**, что обеспечивает строгое аналитическое соответствие законам теоретической механики и баллистики.
* Интегрирование выполняется с постоянным шагом $\Delta t = 0.02$ с (50 Гц) методом **Рунге-Кутты 4-го порядка (RK4)**:
  $$\vec{y}_{n+1} = \vec{y}_n + \frac{\Delta t}{6}\left(\vec{k}_1 + 2\vec{k}_2 + 2\vec{k}_3 + \vec{k}_4\right)$$
* Движение центра масс описывается уравнением Мещерского для тела переменной массы:
  $$m\frac{d\vec{V}}{dt} = \vec{T}(u, \vec{\delta}) + \vec{F}_{aero} + m\vec{g}(\vec{r}) - 2m(\vec{\omega}_\oplus \times \vec{V}) - m\vec{\omega}_\oplus \times (\vec{\omega}_\oplus \times \vec{r})$$
* Вращательное движение твердого тела описывается динамическими уравнениями Эйлера с переменным тензором инерции $\mathbf{J}(m)$ и демпфирующим моментом $m_z^{\omega_z}$.
* Аэродинамический конвективный нагрев носовой части рассчитывается по модели Саттона-Грейвса с равновесной температурой плитки TPS по закону Стефана-Больцмана:
  $$q_{conv} = k_{SG}\sqrt{\frac{\rho}{R_n}}V^3, \quad T_{skin} = \left(\frac{q_{conv}}{\varepsilon \sigma} + T_{atm}^4\right)^{0.25} - 273.15^\circ\text{C}$$
* Высота зажигания двигателей при посадке рассчитывается аналитически по модели Suicide Burn:
  $$h_{ign} = \frac{V_y^2}{2 \cdot \left(\frac{T_{throttle}}{m} - g\right)} + h_{margin}$$
* Механика 4 посадочных опор описывается упруго-диссипативной моделью Кельвина-Фойгта ($K = 80$ кН/м, $C = 30$ кН·с/м, ход штока $\le 1.20$ м).

## 🛠 5. Инструкция по установке, запуску и тестированию

### 1. Запуск симулятора в Unity
1. Откройте **Unity Hub** и добавьте папку `Unity_VTVL_Simulator/` (рекомендуется **Unity 2022.3 LTS** или **Unity 6**).
2. В окне проекта откройте сцену `Assets/Scenes/VTVL_MainFlight.unity`.
3. Нажмите кнопку **Play** в редакторе Unity для старта полета.

### 2. Пакетное тестирование в Unity (Batchmode Fast Sim)
Для запуска автоматического моделирования полного полёта без открытия графического окна:
```bash
/Applications/Unity/Hub/Editor/6000.6.3f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -quit \
  -projectPath Unity_VTVL_Simulator \
  -executeMethod DSTU.VTVL.EditorTools.FlightTestRunner.RunFastFlightSimulation \
  -logFile -
```
По завершении формируются отчеты:
* `FlightReport_VTVL30.csv` — посекундный лог с параметрами высоты, скорости, нагрева, сил и перегрузки;
* `FlightReport_VTVL30.html` — интерактивный веб-отчет с графиками траектории.

### 3. Автоматизированные модульные тесты .NET (28 тестов физики)
Для проверки физических формул (ГОСТ 4401-81, $J_2$, Кориолис, Саттон-Грейвс, Belly-Flop, Кельвин-Фойгт):
```bash
dotnet run --project Tests/PhysicsValidationApp.csproj
```
Результат: 28/28 тестов успешно пройдены (`[PASS]`), посадка на баржу выполняется с ювелирной погрешностью $\le 1.3$ м.

### 4. Управление и ускорение времени (TimeWarp)
В симуляторе реализовано масштабирование времени без потери точности интегрирования (каждый кадр рассчитывает соответствующее число полных шагов RK4):
* **Кнопки в HUD:** `1x` | `10x` | `25x` (правая панель управления с индикацией текущего режима);
* **Горячие клавиши:** `[` (замедлить) / `]` (ускорить: $1\times \leftrightarrow 10\times \leftrightarrow 25\times$);
* **Клавиши пилотирования:**
  - `Space` — Старт / Пауза;
  - `R` — Сброс на стартовый стол A;
  - `Tab` — Переключение автопилот GNC / ручное управление;
  - `W` / `S` — Увеличение / уменьшение тяги маршевой ДУ;
  - `A` / `D` — Тангаж и отклонение сопла TVC;
  - `G` — Интерактивный бортовой отчёт полёта и графики телеметрии;
  - `1` / `2` / `3` / `4` — Переключение камер обзора (хвостовая, боковая, стартовый стол A, баржа B).
