# Интерактивный симулятор суборбитальной ракеты VTVL-30 (Кейс 8.1 ДГТУ)

Проект разработан в рамках роли **ИТ-1 (Ведущий разработчик / Архитектор ядра физики)** для команды №03.

## 🚀 Назначение
Веб-симулятор обеспечивает визуализацию полного профиля суборбитального полёта ракеты-носителя вертикального взлёта и посадки (VTVL) по траектории **A (Стартовый стол) ➔ C (Суборбитальный апогей > 100 км, линия Кармана) ➔ B (Посадочная плавучая баржа ASDS на удалении 25.3 км)**.

## 🕹 Управление
* **Пробел (Space)** — Старт симуляции / Пауза
* **Tab** — Переключение между **АВТОПИЛОТОМ (GNC)** и **РУЧНЫМ УПРАВЛЕНИЕМ**
* **W / S (Стрелки Вверх / Вниз)** — Регулировка тяги двигателя (0%..100%)
* **A / D (Стрелки Влево / Вправо)** — Ручное управление углом тангажа ракеты
* **Кнопка «Панорама» / «Слежение»** — Переключение режимов камеры (глобальный обзор траектории или кинематографический зум)
* **1x / 2x / 5x / 10x** — Ускорение времени (Time Warp)
* **Скачать CSV** — Экспорт полной телеметрии полёта (время, координаты, скорости, перегрузка, массы) для сравнения с эталонными таблицами

## 🧮 Реализованные физические модели
1. **Численное интегрирование:**
   * Метод Рунге-Кутты 4-го порядка (RK4) с шагом $\Delta t = 0.01 \dots 0.05$ с;
   * Метод Эйлера 1-го порядка для оценки точности и погрешности.
2. **Атмосфера ГОСТ 4401-81:**
   * Узлы от 0 до 120 км;
   * Точный расчёт температуры $T(h)$, давления $P(h)$, плотности $\rho(h)$ и скорости звука $a(h)$.
3. **Аэродинамика:**
   * Расчёт динамического напора $q = \frac{1}{2}\rho v^2$;
   * Зависимость коэффициента лобового сопротивления $C_d(Mach)$ с трансзвуковым волновым кризисом;
   * Моделирование эффективной площади торможения при спуске кормой вперёд и раскрытии решётчатых рулей (Grid Fins).
4. **Гравитация Ньютона:**
   * $g(h) = g_0 \cdot \left(\frac{R_E}{R_E + h}\right)^2$ с $R_E = 6\,371\,000$ м.
5. **Автопилот GNC и Hoverslam:**
   * Плавный гравитационный разворот тангажа;
   * Разворот ступеней в космосе соплами RCS;
   * Аналитическое включение посадочного тормозного импульса (Suicide Burn) с мягким касанием $v_y \le 2.0$ м/с на палубу баржи B.
