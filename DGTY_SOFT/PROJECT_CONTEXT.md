## 📌 СУТЬ ЗАДАЧИ

**Цель:** Спроектировать прототип симулятора вертикального взлёта и посадки ракеты.

В интерактивной модели игрок управляет ракетой с **реалистичной физикой**:
- Тяга двигателя
- Гравитация
- Аэродинамическое сопротивление
- Расход топлива

**Метод:** Численное интегрирование — метод Эйлера **или** Рунге-Кутта 4-го порядка (RK4) для обновления состояния.

**Система обучения:**
- Подсказки и туториал
- Уровни сложности
- Отображение ключевых параметров: скорость, высота, остаток топлива, перегрузка

**Дополнительно:** Оценить влияние шага интегрирования на стабильность симуляции.

### Задача 2. Математическая модель и расчёт параметров
**Ведущая роль:** 📐 Конструкторы-расчётчики  
**Поддержка:** 🔬 Исследователи, 💻 IT-специалисты

**Содержание:**
Вывести уравнения движения, выбрать параметры ракеты. Проверить размерности, тяговооружённость, расход топлива, перегрузку.

**Уравнения движения:**
```
ma = F_thrust - mg - F_drag
F_drag = 0.5 * Cd * ρ * A * v²
dm/dt = -ṁ (расход топлива при тяге)
```

**Критерии выполнения:**
- [ ] Формулы записаны и объяснены
- [ ] Таблица параметров с единицами измерения
- [ ] Проверка: при u=0 ракета падает с ускорением, близким к g
- [ ] При u=1 и полном баке: T/(mg) > 1 (TWR > 1)
- [ ] Масса не становится отрицательной
- [ ] Расход топлива за 10 секунд совпадает с ручным расчётом
- [ ] Построены графики h(t), v(t), m(t) для тестового полёта

## 🔑 КЛЮЧЕВЫЕ ПАРАМЕТРЫ ФИЗИКИ

| Параметр | Обозначение | Описание |
|----------|-------------|----------|
| Позиция | r = (x, y, z) | координаты ракеты в 3D пространстве (м) |
| Скорость | v = (v_x, v_y, v_z) | вектор скорости (м/с), v_y — вертикальная |
| Масса | m | текущая масса ракеты (кг) |
| Масса топлива | m_fuel | остаток топлива (кг), m = m_dry + m_fuel |
| Тяга | F_thrust / u | управляемая тяга [0..1], дросселирование 40%–100% |
| Гравитация | g(h) | переменная: g(h) = g₀ · (R_E / (R_E + h))² |
| Плотность воздуха | ρ(h) | переменная по ISA (тропо/страто/мезосфера) |
| Коэф. сопротивления | Cd(Mach) | переменный: зависит от числа Маха |
| TWR | T/(mg) | тяговооружённость, > 1 чтобы взлететь |
| Перегрузка | n | n = \|F_thrust + F_drag\| / (m · g₀) |
| Расход топлива | ṁ | ṁ = T / (Isp · g₀) кг/с |

> **Примечание о двухэтапной модели:**
> - **1D-эталон (верификация):** используются постоянные g = 9.81, ρ = const, Cd = const для ручного расчёта в Excel (КР-7) и сравнения интеграторов Euler vs RK4 при разных Δt.
> - **3D-симулятор (основной продукт):** полная векторная физика с переменными g(h), ISA-атмосферой, Cd(Mach) и суборбитальным профилем A→C→B.

## 📊 ТЕХНИЧЕСКИЙ СТЕК И АРХИТЕКТУРА

- **Язык:** C# (.NET) — строгая типизация, высокая производительность
- **Платформа / Движок:** Unity 2022.3 LTS (3D-визуализация, шейдеры атмосферы/нагрева, UI/HUD)
- **Физическое ядро:** Собственный 3D численный интегратор (Euler + RK4) на C# без привязки к PhysX
  - Вектор состояния: позиция (x,y,z), скорость (v_x,v_y,v_z), ориентация (кватернион), угловые скорости, масса
  - 1D-режим используется только для верификации формул и сравнения с эталоном Excel
- **Модель гравитации:** Переменное гравитационное поле Ньютона $g(h) = g_0 \cdot \left(\frac{R_E}{R_E + h}\right)^2$
- **Модель атмосферы:**
  - **Для 1D-эталона (КР-7):** упрощённая экспонента ρ(h) = 1.225 · exp(−h / 8500)
  - **Для 3D-симулятора:** полная ISA (0–120 км) с термодинамическими слоями (тропосфера, стратосфера, мезосфера)
- **Формула перегрузки:** $n = \frac{|\vec{F}_{thrust} + \vec{F}_{drag}|}{m \cdot g_0}$ (при свободном падении n = 0G — невесомость, при старте n ≈ 2–3G)
- **Профиль полёта:** Полный космический цикл A→C→B (взлёт со стола, гравитационный поворот, выход за Линию Кармана >100 км, гиперзвуковой вход с нагревом, управляемый Suicide Burn)
- **Suicide Burn:** Алгоритм с учётом переменной массы m(t) при сгорании топлива; минимальный предел дросселирования двигателя — 40% (зависание невозможно)
- **Управление:** Двойное — ручное (MANUAL) и адаптивный автопилот (AUTO) с мгновенным переключением по клавише TAB
- **Данные и телеметрия:** Экспорт в CSV через `System.IO.StreamWriter` (графики в Excel/Python)
- **Тестирование:** Автоматические модульные тесты Unity Test Framework (NUnit)
