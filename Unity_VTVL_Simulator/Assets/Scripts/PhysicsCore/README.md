# C# Ядро физики ракеты-носителя VTVL-30 (Unity 2022.3 LTS)

Разработано в рамках роли **ИТ-1 (Ведущий разработчик / Архитектор ядра физики)** для Кейса 8.1 ДГТУ (Группа №03).

---

## 📁 Структура папки `PhysicsCore_CSharp/`

```text
PhysicsCore_CSharp/
├── Core/                               # Чистая математика и физика (без зависимостей от Unity)
│   ├── RocketParameters.cs             # Физические константы, паспорт VTVL-30 (30т, 450кН, Isp 300с)
│   ├── RocketState.cs                  # 14-мерный вектор состояния задачи Коши (координаты, скорости, углы, масса)
│   ├── AtmosphereGOST4401.cs           # Стандартная атмосфера ГОСТ 4401-81 (0..120 км, T, P, rho, a)
│   ├── AerodynamicsModel.cs            # Модель лобового сопротивления Cd(Mach), скоростной напор q, решётчатые рули
│   ├── GravityModel.cs                 # Закон всемирного тяготения Ньютона g(h) = g0 * (Re / (Re + h))^2
│   ├── CauchyDerivatives.cs            # Вычисление правых частей системы 14 ОДУ: dY/dt = f(Y, U, t)
│   ├── RK4Integrator.cs                # Численный интегратор Рунге-Кутты 4-го порядка точности O(dt^4)
│   └── EulerIntegrator.cs              # Численный интегратор 1-го порядка Эйлера для сравнения погрешности
│
├── Guidance/                           # Автопилот и система наведения (GNC)
│   ├── AutopilotGNC.cs                 # Профиль полёта A -> C -> B (подъём, гравитационный разворот, апогей, спуск)
│   └── SuicideBurnCalculator.cs        # Аналитический расчёт и контур управления посадкой Hoverslam
│
└── UnityAdapters/                      # Компоненты интеграции с Unity 2022.3 LTS
    ├── RocketPhysicsBridge.cs          # MonoBehaviour: запускает RK4 в FixedUpdate (БЕЗ Rigidbody и PhysX!)
    └── TelemetryLogger.cs              # Логирование телеметрии в CSV-формат по ГОСТ для жюри
```

## ⚡ Ключевые архитектурные принципы

1. **Полная независимость от PhysX / Rigidbody:**
   * Регламент Кейса 8.1 запрещает использование встроенной физики Unity (PhysX), так как она не решает задачу Коши и не учитывает переменную массу ступени по формуле Циолковского.
   * `RocketPhysicsBridge.cs` самостоятельно интегрирует уравнения движения через `RK4Integrator.Step(...)` и напрямую обновляет координаты объекта `transform.position` и `transform.rotation`.

2. **Математическая строгость:**
   * **14-мерный вектор состояния Коши:**
     $$\vec{Y} = [x, y, z, v_x, v_y, v_z, \theta, \psi, \gamma, \omega_x, \omega_y, \omega_z, m, m_{fuel}]^T$$
   * **Атмосфера ГОСТ 4401-81:** точная интерполяция по 15 реперным высотам от 0 до 120 км.
   * **Переменная масса Циолковского:**
     $$\dot{m} = -\frac{T}{I_{sp} \cdot g_0}$$
   * **Реакция опоры стартового стола:** при $y \le 0$ и тяге $T < mg$ ракета неподвижно стоит на столе без проваливания под текстуры.

3. **Мягкая посадка (Hoverslam / Suicide Burn):**
   * Замкнутый контур управления тягой рассчитывает требуемое замедление $a_{req} = \frac{v_y^2}{2 y}$ и удерживает вертикальную скорость касания в диапазоне **$-1.5 \dots -2.5$ м/с** при отклонении от центра баржи B менее 50 метров.

## 🛠 Инструкция по подключению в Unity 2022.3 LTS

1. Скопируйте папку `PhysicsCore_CSharp` в ваш проект Unity в каталог `Assets/Scripts/`:
   ```bash
   cp -r PhysicsCore_CSharp/ <Путь_к_Unity_проекту>/Assets/Scripts/PhysicsCore/
   ```
2. Создайте пустой игровой объект (GameObject) в сцене Unity и назовите его `Rocket_VTVL30`.
3. Добавьте на него компонент `RocketPhysicsBridge.cs`:
   * В инспекторе выберите метод интегрирования: **RungeKutta4** (рекомендуется) или **EulerExplicit**.
   * Задайте `Simulation Fixed Dt = 0.01`.
   * Прикрепите префабы визуализации пламени (`MainEnginePlume`), сопел RCS и решётчатых рулей.
4. Добавьте компонент `TelemetryLogger.cs` для автоматической записи CSV-файла телеметрии во время полёта.
5. Нажмите **Play** в редакторе Unity — ракета выполнит полностью автоматический суборбитальный полёт $A \to C \to B$ с мягкой посадкой на баржу!
